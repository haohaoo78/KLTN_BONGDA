API và migration

Gateway → Match: GET/POST /api/tournaments/:id/referee-team; GET …/account-lookup?email=…; PATCH …/:memberId; POST …/:memberId/resend-access. Auth nội bộ kiểm tra BTC thật và quyền quản lý giải. Email dùng POST /internal/email/referee-team-access đã bảo vệ bằng khóa nội bộ.

Migration bổ sung, đã sao lưu PostgreSQL trước khi áp dụng: Auth account v9 (cấp tài khoản/idempotency), Match scheduling v1009 (profile, thành viên, lần gửi), Notification v7 (sổ email chống trùng). Không sửa migration đã áp dụng, không truy cập chéo database giữa service, không reset hay xóa volume.
